Install Hiwar

Install Hiwar like a regular app — it gets its own icon, opens full-screen, and works offline.

🤖 Android (Chrome)

  1. Tap the ⋮ menu (top-right of Chrome)
  2. Tap Install app or Add to Home screen

🍎 iPhone / iPad (Safari)

  1. Tap the Share button (⬆️)
  2. Scroll down and tap Add to Home Screen
  3. Tap Add

💻 Windows desktop app

  1. Open the Hiwar releases page
  2. Download Hiwar Setup for a normal install, or the portable .exe to run it without installing
  3. No admin rights needed — the installer can install for your user only

🌐 Chrome or Edge on a laptop

  1. Click the install icon in the address bar, or the browser menu → Install Hiwar
  2. It opens in its own window and works offline

Settings
